# Ketner Station

Голосовой ассистент для Windows в духе «Яндекс Станции с Алисой», но для вашего компьютера. Запускается вместе с Windows, живёт в трее без окон и слушает микрофон. Скажите **«Кетнер»**, дождитесь сигнала и назовите команду:

- «Кетнер, открой Яндекс Музыку» · «открой Discord» · «открой GitHub» · «открой Claude»
- «сделай потише» · «следующий трек» · «пауза»
- «найди в интернете рецепт борща» · «поставь таймер на 10 минут»
- «сверни все окна» · «открой папку загрузки» · «заблокируй экран»
- «выключи компьютер» (спросит подтверждение и даст 15 секунд на отмену)

Ответы озвучиваются на выбранное устройство вывода, например на вашу колонку или усилитель (Nux, AMP), а все параметры меняются в окне настроек.

## Как это работает

```
микрофон ─► Vosk (офлайн) ─► слово «Кетнер» + конец фразы
                              │
                              └─► запись фразы ─► Whisper (офлайн, точный текст команды)
                                                              │
                              простая команда («пауза») ◄─────┤
                                                              ▼
                              Ketner AI API (/v1/chat/completions, вызов функций)
                                                              │ выбирает инструменты
                                                              ▼
   открыть программу/сайт · клавиши · мышь · громкость · окна · файлы · питание · PowerShell
                                                              │
колонка ◄─ Piper (офлайн) или голос Windows ◄─ короткий ответ ┘
```

- **Распознавание речи** целиком локальное, звук с микрофона никуда не отправляется. Слово «Кетнер» и конец фразы ловит быстрый Vosk (~45 МБ), а текст самой команды заново расшифровывает **Whisper** (whisper.cpp, модель small ~180 МБ): он намного точнее Vosk. Если Whisper недоступен, берётся текст Vosk.
- **Команды понимает Ketner AI**: в API уходит только распознанный текст команды и список инструментов. Нужен ключ `ketner_sk_…` (тариф Plus и выше), адрес и модель настраиваются; подойдёт любой OpenAI-совместимый сервер с вызовом функций.
- **Озвучка** локальная: Piper (русские голоса Ирина, Денис, Дмитрий, Руслан) с выбором колонки либо голос Windows.
- Простые команды (пауза, громче, тише, дальше) выполняются сразу, без запроса к модели.

## Установка

1. Скачайте установщик `Ketner Station Setup *.exe` из артефактов сборки (GitHub Actions → последний запуск → `Ketner-Station-Setup`) или соберите сами (см. ниже).
2. Установите и запустите. Откроются настройки: вставьте ключ API на вкладке **Ketner AI** и нажмите «Сохранить и проверить».
3. При первом запуске скачиваются Vosk (~45 МБ), Whisper (~180 МБ) и голос (~85 МБ). Прогресс виден на вкладке **Состояние**. Пока Whisper не скачан, команды распознаёт Vosk, то есть хуже.
4. Во вкладке **Голос и звук** выберите микрофон и колонку, нажмите «Подобрать по голосу» и три раза скажите «Кетнер»: приложение запомнит, как именно распознавание слышит это слово.

Если что-то не работает, откройте **Журнал и проверка** и нажмите «Проверить функции Windows»: приложение проверит PowerShell, меню «Пуск», нажатие клавиш и связь с Ketner AI и покажет, что именно сломано.

Дальше Ketner Station стартует вместе с Windows тихо, значок в трее. Клик по значку открывает настройки, правый клик даёт меню: «Говорить сейчас», «Выключить микрофон», «Выход».

Горячая клавиша **Ctrl+Alt+K** (настраивается) включает прослушивание без слова активации и прерывает речь ассистента.

## Настройки

| Вкладка | Что настраивается |
| --- | --- |
| Состояние | Загрузка моделей, проверка связи с Ketner AI |
| Голос и звук | Расшифровка команд (Whisper/Vosk, модель), слова активации и их калибровка, чувствительность, микрофон, **колонка**, громкость, сигналы, голос и скорость речи, горячая клавиша, «продолжать разговор» |
| Ketner AI | Ключ (хранится зашифрованно, Windows DPAPI), адрес API, модель, шаги, температура, поисковик |
| Приложения и сайты | Свои прозвища программ и сайтов, пути и аргументы запуска |
| Безопасность | Режим подтверждений, автозапуск, отладочный журнал распознавания |
| Журнал и проверка | Что услышал и сделал ассистент; команду можно напечатать вместо голоса |

Программы из меню «Пуск» ассистент находит сам: перечислять их не нужно. В список добавляйте портативные программы, скрипты и свои названия.

## Безопасность

Ассистент способен запускать программы, нажимать клавиши и выполнять команды PowerShell, а распознавание речи иногда ошибается. Поэтому по умолчанию **опасное подтверждается голосом**: удаление файлов (только в корзину), выключение, перезагрузка и сон, закрытие программ и окон, любые команды PowerShell, клавиши Delete и Alt+F4. Ассистент зачитывает, что собирается сделать, и ждёт «да» или «нет»; молчание считается отказом. Режим можно сменить на «спрашивать всегда» или «никогда» (на свой риск).

Чего ассистент **не делает**: не видит экран (модель получает только текст), поэтому «кликни вот сюда» не работает. Мышь доступна только в текущей позиции курсора. Голос говорящего не проверяется: «Кетнер» может сказать любой человек рядом с микрофоном.

## Разработка

Нужен Node.js 22.12+.

```bash
npm install
npm run dev          # сборка и запуск с отладочными окнами
npm test             # тесты логики (разбор слова активации, диалог, инструменты, агент)
npm run typecheck
npm run dist         # установщик Windows (запускать на Windows) → release/
npm run icons        # перерисовать иконки (build/icon.ico, resources/*.png)
```

Структура:

```
src/main/       главный процесс: трей, окна, инструменты Windows, клиент Ketner AI, загрузка моделей, Piper
src/preload/    безопасный мост между окнами и главным процессом
src/renderer/audio/     скрытое окно: микрофон, Vosk, озвучка, сигналы
src/renderer/settings/  окно настроек
src/shared/     то, что работает и в окнах, и в главном процессе: конфиг, разбор речи, автомат диалога
```

Управление компьютером реализовано на Windows API через PowerShell (`keybd_event`, `mouse_event`, `Get-StartApps`), поэтому на других системах интерфейс запускается, а команды возвращают «доступно только в Windows».

## Известные ограничения

- Слова «Кетнер» может не быть в словаре русской модели Vosk: распознавание подставляет похожие слова. Для этого есть калибровка по голосу и список вариантов; при слабом качестве поможет включить «Показывать всё, что слышит распознавание» и добавить увиденные варианты.
- Выбор колонки работает для голоса Piper и сигналов. Голос Windows (запасной вариант) играет на устройстве по умолчанию.
- Если ассистент задаёт вопрос, он слушает ответ сразу, без слова «Кетнер».
- Whisper на процессоре тратит 1–3 секунды на фразу; для слабых компьютеров есть модель base.
- Таймеры живут, пока приложение запущено.
- Автозапуск работает у установленной версии, не у запуска из исходников.
